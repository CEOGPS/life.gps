LIFEOS ONE — Complete Project Summary
1. CONCEPT & MISSION
Concept: LifeOS One is a secure, AI-powered "super-app" and personal operating system that unifies every aspect of a user's personal life and professional business into a single login. It functions as a personal command center, replacing dozens of fragmented apps with one intelligent dashboard. And to do this at no cost, proving it can be done and better than most paid services.

Mission:
"One Login. Your Entire Life."
"Grow faster. Connect deeper. Live simpler."
Core Purpose: Eliminate app-switching fatigue by collapsing social media, CRM, family management, calendars, lead generation, events, learning, community networking, career tools, and autonomous AI agents into one privacy-first platform that turns scattered data into actionable intelligence.

4. TECHNICAL ARCHITECTURE
Database & Backend
Primary: Supabase PostgreSQL (Auth, relational data, Row Level Security)
Vector Search: pgvector (1536-dim embeddings for semantic search/AI memory)
Graph Database: Neo4j (relationship graph for Opportunity Engine, Capital Scoring, complex traversals)
Realtime: Supabase Realtime (WebSockets for instant dashboard updates)
Edge Functions: Deno-based (embeddings generation, Neo4j sync)
Key Data Tables
profiles (users)
contacts (family, friends, clients, prospects)
contact_consents (privacy-first consent levels)
events (unified personal/family/business calendar with energy levels)
businesses & leads_opportunities (CRM core)
embeddings (vector store for AI insights)
life_insights (LifeOS Pulse storage)
promoted_events (event ticketing/promotion)
social_connections (linked external accounts)
messages & chats (full Messenger-style messaging)
karaoke_duets (entertainment feature)
AI/ML Stack
LLM: Groq (Llama 3.3 70B / Llama 4 Scout) — free tier, 280–400+ tokens/sec
Embeddings: HuggingFace (all-MiniLM-L6-v2) — 100% free
Agent Framework: LangGraph with manual supervisor architecture
Memory: PostgresSaver for persistent agent state
Vector Store: SupabaseVectorStore
Agent System (Multi-Agent Supervisor)
LifeOS Conductor (Supervisor) — Routes requests to specialized agents using structured Pydantic output
Opportunity Engine Agent — Finds ethical warm leads from consented signals
Conflict Resolver Agent — Detects and fixes calendar/family/business conflicts
Life Audit Agent — Generates cross-domain insights and life hacks
Karaoke Duet Agent — Pure entertainment/creative mode
Frontend & Infrastructure
Frontend: Next.js 15 (App Router, React, Tailwind CSS)
Backend API: FastAPI (Python) with streaming SSE support
Authentication: Supabase JWT with middleware verification
Rate Limiting: slowapi (10 req/min per IP)
Deployment: Docker + Docker Compose + Nginx reverse proxy + Let's Encrypt HTTPS
CI/CD: GitHub Actions (lint, test, build, push to GHCR, auto-deploy to staging/production with manual approval gates)
Hosting: Oracle Cloud Always-Free ARM VM (zero cost) + Vercel (frontend)
