# Erebus Browser Agent

Puppeteer-based browser automation for Erebus. Runs locally at `http://localhost:8100`.

## Setup

```bash
cd browser_agent
npm install
cp .env.example .env
npm start
```

## Start with LifeOS1

Add to your LifeOS1 startup script or run separately in a terminal.
The Erebus panel will auto-detect this agent and enable web browsing commands.
