# Deployment Guide

## Prerequisites

1. **Accounts Needed:**
   - Supabase (https://supabase.com)
   - Vercel (https://vercel.com) or similar host
   - ZeroBounce (https://zerobounce.net)
   - SendGrid (https://sendgrid.com)
   - Brevo (https://brevo.com)
   - LinkedIn API access (optional)
   - Zoom API access (optional)

2. **Local Setup:**

```bash
# Clone and install
git clone <your-repo>
npm install

# Set up environment variables
cp .env.example .env.local

# Run development server
npm run dev
```
